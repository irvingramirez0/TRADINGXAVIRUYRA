# Test de las últimas 50 rupturas de regla

> **Confianza:** explícito · **Estado:** vigente · **Versión:** 1

## Descripción

Antes de buscar trucos, contar las últimas 50 veces que se rompió una regla y cuántas acabaron bien: el resultado es cero. Si cuando sale bien acaba saliendo mal y cuando sale mal sale mal, no tiene sentido seguir.
