# Si no hay gap relevante, no mover break-even

> **Confianza:** explícito · **Estado:** vigente · **Versión:** 1

## Descripción

Cuando el low/high que se quiere usar para BE no está dentro de ningún gap/zona, no se mueve el stop: se deja que el trade haga TP o SL.
