Este sitio se presenta como un resumen **trazable**. Esta página es su propia auditoría: enumera lo que no tiene fuente y, por tanto, no debería tomarse como establecido.

## Cómo leer una nota

| Marca | Significado |
|---|---|
| **explícito** | Se dice literalmente en un vídeo; la nota incluye la cita y el minuto. |
| **observado** | Se deduce de un ejemplo o un recap, no de una regla formulada. |
| **inferido** | Interpretación del proyecto a partir de varias fuentes. |
| **no confirmado** | No hay fuente suficiente. Figura aquí abajo si aplica. |

## Regla del proyecto

Cuando no hay fuente, no se rellena: se marca. Las anotaciones de fotogramas y las preguntas abiertas existen para eso, y por eso el sitio puede decir en voz alta lo que todavía no sabe.
