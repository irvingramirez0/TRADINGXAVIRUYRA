> **Confianza:** explícito · **Estado:** vigente · **Categoría:** CORE

## Definición

Para Xavi, un PD array es un fair value gap.

## Interpretación de Xavi

'Un PD array viene a ser un fair value gap.' No lo usa como una categoría amplia de ICT; lo equipara al FVG.

## Cómo identificarlo

Igual que un FVG: tres velas, mechas 1 y 3 no se tocan.

## Cuándo se usa

Cuando habla de DOL dentro de un PD array.

## Condiciones

Mismas que el FVG.

## Temporalidades

4H/1H/15m/5m.

## Aplicación

Sirve para explicar por qué un high/low tiene peso: está dentro de un PD array/FVG.

## Errores comunes

Interpretarlo como una categoría ICT más amplia; añadir order blocks, breakers u otros elementos que él no usa.

## Excepciones

Ninguna documentada.

## Notas

Documento 03. No ampliar el término con ICT genérico.
